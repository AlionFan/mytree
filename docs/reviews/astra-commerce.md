## 官网与套餐展示

官网顺序：产品价值与开始学习 → 原创数学演示 → 拍题/引导/练习/知识树闭环 → 电脑与手机实际界面 → 免费及付费方案 → 硬件组合 → 常见问题及完整页脚。登录后的学习桌保持紧凑，不用营销首屏挡住任务。截图使用当前版本隔离演示档案，保留完整画面比例并可放大，不用object-fit:cover裁掉题目和按钮；手机上不要将三张桌面图硬挤成不可读的一行。

Brilliant当前公开页具有分块产品介绍、交互学习说明、认证与用户评价，参考其信息层次；本项目用自己的数学演示和产品证据。无本项目真实奖项/认证/评论数据时，改展示可验证功能、开发进展或实际示例，不填虚构奖章与人数。不上架阶段展示“网页版”“Android测试版”等真实入口与设备画面，不使用会让人误以为已上架的商店下载按钮。

至少两种原创数学动态演示，数学关系可独立核验，例如平方差面积分解、数轴定义域或相似面积/边长关系。每段有明确起止和解释；支持暂停或减少动态效果，离屏停止，失败显示静态关键帧；首屏不等待全部视频下载。演示不得冒充用户题目的实时AI结果，不从参考站热链整段品牌视频。

套餐采用免费、两档有界用量软件会员以及长期硬件组合的候选结构；这是Astra展示建议，不是已确定售价/用量。不要在成本未知时宣传不限量。对比表必须写明拍题按题计数、探索按图片识别计数、对应练习是否包含、讲解/语音/作图边界、计费周期、总付款额、有效期及硬件赠送条件。年付折算月价必须同时突出实际年付总额；月年切换不得留下旧额度或旧总价。未确定权益标为待定，不用勾选图标暗示已经交付。

## 免费计量口径（本批设计决定）

- 服务端以已认证账号为额度主体；同账号家长/孩子、不同设备共享额度。采用Asia/Shanghai自然日及自然月，返回准确reset_at；登录退出、重启、修改设备时钟不重置次数，旧账号首次初始化不得损坏学习数据。
- **每天3题，不是3张图片。** 一张含10题的照片可以完成选题，但只能将剩余额度允许的题目接收进入学习；先展示题序与可选项，不能先把10题完整讲解全部交付后只计1次。每个成功接收的独立题目计1；analysis和lesson_only都属于学习成功。同一已接收题的刷新、重开、恢复、失败重试不重复计费；不能靠换请求ID在同一批同一道题反复扣次。不同次新上传暂按新任务计，避免宣称已具备跨图片语义去重。
- 来源失败、无法接收、上游超时、取消不耗用户成功次数。先原子预留、成功提交、失败释放；并发请求不能超额，进程中断的悬挂预留可恢复。同一题多次按钮请求必须业务幂等，不能多建卡多扣数。来源核验失败仍按原有规则拒绝，不为额度计数放松数学与图片边界。
- 这3题已有的对应拓展练习及提交不再占上传题额度；次日仍能打开其记录、继续复习与知识树操作。没有同结构练习支持时继续如实说明，不用无关简单题兑现“对应练习”。讲解、语音和图形的资源限制需明确配置，不能因“包含练习”暗含无限模型调用。
- **探索每月10次成功的用户发起图片识别。** 一次发起只形成一次识别结果；连续预览/取暖帧/后台活动不扣，后台不自动连续识别。得到结果后再次识别由用户明确触发，并可见剩余额度；失败与相同请求重试不重复扣。不能将10次解释成10个无限帧会话，也不能一次打开相机就自动耗尽10次。
- 所有能触发同一收费能力的业务入口都走同一服务端计量，不只禁用前端按钮。匿名入口不能绕过账号额度，客户端不能提交owner/plan/used来自行升级。OCR发现题目可能产生的成本以独立速率/并发/大小限制控制，不假冒题目成功消费；限制和失败要能恢复。

## 支付与硬件边界

商户尚未配置时，可以完成套餐选择、价格说明和不可付款状态；不能按“开通”按钮即授予会员，不能把pending订单写成已付款。测试支付与真实收款显式分开。真实支付接入后，金额/币种/套餐版本由服务器决定，以已验证的供应商付款结果更新权益；不能信任前端跳转成功参数。重复通知、乱序通知、延迟通知、取消、到期、退款与升级必须有明确定义和幂等记录。未知商户时先做接口边界与测试，不虚构某家支付商已接通。真实收费前的商户配置由用户本地安全输入，普通日志不存凭据。

长期硬件组合可先做标明概念/待定的展示。只有型号、成本、赠送资格、库存/交付时间、运费、售后和退款处理明确后才能形成可购买承诺。软件权益和硬件履约分开记录；支付成功不等于硬件已发货，重复回调不能重复生成赠品。用户未提供BOM前不写确定赠品价值、确定发货日或“免费赠送无条件”。不购买、不备货、不收集无必要的收货信息。

## 成本测算交付

由Codex提供可复算表，供应商价目与获取日期用实际官方/NextLabs资料核实，已发生调用用脱敏usage统计；金额/汇率/费率不凭记忆写成当前事实。分别计算读图、讲解多轮、作图、ASR、TTS、失败重试、存储与流量、主机/邮件、支付费用和支持成本。给低/典型/高使用量与套餐满额情景，列样本量和估算假设；不能只按一次OCR的token成本定整月价。

硬件总成本包含BOM、组装测试、包装物流、损耗/保修及服务期限内的软件成本；年付现金收入不等于当月利润。成本不齐时输出价格区间和敏感性分析，未知项留空/明确假设，不伪造精确盈亏。方案审批与真实可收款状态分开，未形成成本证据不发布确定价格保证。
