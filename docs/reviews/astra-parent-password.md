# 同账号家长入口：设计与迁移验收

2026-11-15，astra-lead；执行codex-parent，server/PRD集成codex-android。FR-033/FR-018，覆盖旧邀请配对设计。已读取用户原话：同账号区分家长/孩子端，首次设密码，以后进入确认密码，可独立页面，配对正确且操作简便。本文件是设计决定，不代表实现已通过。

## 确定的交互

保留独立`/parent`，账号菜单提供家长入口，不放进孩子主任务导航。未登录先邮箱登录，next固定返回家长页。服务端以基础登录账号的profile_id确定唯一学习档案；不要求孩子邀请，不输孩子邮箱或编号，不从URL/请求体选择档案。页面简洁标明“当前账号的学习记录”。

首次：当前账号邮箱验证一次→设置家长密码与确认→进入。该次验证属于新增设计参数，用来避免仅持有孩子端已登录设备的人直接抢设密码；不要求每次验证码。若可安全复用刚完成的、目的明确且未消费的短期验证凭证可减少步骤，但不能仅凭7天基础登录Cookie认定刚验证过。普通进入仅一个家长密码输入框；允许粘贴、密码管理器和显示密码，无拼图或复杂组合规则。密码本批8～128字符；不可静默截断。忘记密码：当前邮箱一次新验证→重设，旧密码和全部家长会话失效。邮箱控制者能重设，这不是法律监护身份核验。

家长看板保持只读，不借此开放改答案、分数、知识树或管理后台。返回孩子端不注销基础账号。家长密码与邮箱登录验证码分别命名，不能把它暗改为整个账号的登录密码。

## 会话与接口边界

- 家长会话15分钟绝对有效，不因读取自动续期；随机不透明令牌，数据库保存摘要，绑定基础会话摘要、账号及家长密码版本。每次读取都确认基础会话仍有效，不能只比邮箱。基础退出/换账号/过期立即使家长权限失效。
- 家长Cookie独立、HttpOnly、Secure、SameSite，服务端校验同源写请求。锁定或返回孩子端调用明确锁定API撤销家长会话并清Cookie；不依靠仅前端隐藏。
- 刷新、重新进入和历史缓存恢复先显示密码屏，不自动请求/展示摘要。后台先遮蔽敏感DOM，恢复需确认密码；pagehide/隐藏时可尽力撤销，但网络失败或进程被杀不能声称立即撤销，服务器15分钟期限仍是兜底。主动锁定必须等待服务端成功或显示未完成状态。
- 请求验证码的目的区分parent_setup/parent_reset，绑定当前账号且10分钟单次有效；不能将普通登录码交叉用于设置/重置。消费验证码与密码写入/版本升级必须有一致的事务边界；并发首次设置只能一方成功，不能“后来设置覆盖已有密码”。
- 状态接口仅给当前登录者返回是否已设置/是否需解锁，不返回学习摘要。父级受保护摘要在未解锁时403；未基础登录401。限流429附可理解重试时间，错密码不返回其他账号信息。
- 密码使用带随机盐的慢哈希，不沿用验证码HMAC作为密码哈希。可选scrypt或Argon2id，参数按部署资源测量并记录；参考[OWASP密码存储建议](https://cheatsheetseries.owasp.org/cheatsheets/Password_Storage_Cheat_Sheet.html)。失败按账号+来源限流，5次失败后短暂冷却，冷却时间和重置路径明确；不能无限尝试，也不永久锁死账号。

接口具体名称由双方固定并先交换：status、send-code、setup、unlock、reset、lock、summary；server接线前明确字段/响应/错误与Cookie处理。家长模块不能自己信任调用者传来的profile_id；由server的真实基础会话身份传入或模块再次核对。独立确认接口不以客户端布尔值parent=true授权。

## 旧邀请关系迁移

旧family_invites和family_links不再提供读取授权。旧invite/accept入口及API关闭（明确410或等价不再支持错误）；旧overview不能继续返回跨邮箱孩子摘要，避免新家长页上锁而旧API仍可读。旧revoke可以安全保留为仅撤销旧关系的兼容操作，也可返回停用，不允许创建新授权。

不删除或复制任何学习档案，不把旧家长邮箱绑定到旧孩子profile_id，不为旧关系自动设置家长密码，不将旧账号合并。旧关系表可保留为停用历史数据，本批无须物理清表；再次开启旧功能必须另有明确决定。原有跨邮箱家长账号登录后只对应它自己的档案，空档案显示暂无学习记录。新旧部署不能并存一个仍接受旧分享授权的服务实例。

PRD应一致更新FR-011相关家长入口、FR-033、数据对象/状态表及AC-P5，历史通过记录保留并注明被新方案替代；不能只追加一行而让旧邀请要求继续作为当前功能。decisions记录最新用户要求覆盖旧邀请设计。

## 独立验收清单

1. 同账号首次设置→进入摘要→返回孩子→再次输入密码；手机375/390、短横屏与Android WebView可用，密码不进入URL/日志/截图证据。
2. 账号A、B分别有不同数据：A家长只见A；改URL/body/student/profile_id、复用A家长Cookie加B基础Cookie均被拒绝。没有选择错误孩子的路径。
3. 错码、过期、重用、错误用途、跨账号验证码；并发首次设置；发送失败不清空输入且可恢复。真实邮箱验证与本机模拟证据分别记录。
4. 错密码与限流、成功解锁、15分钟过期、锁定、基础退出/换账号、重置密码后的所有旧会话；只修改前端无法绕过。
5. 刷新、后退/前进缓存、切后台、关闭重开页面无旧摘要闪现；网络断开锁定不假称已服务端撤销；基本登录不因家长锁定退出。
6. 预置旧邀请/旧已接受关系，旧overview/invite/accept不能读他人或恢复授权；迁移前后学习事件、树、练习记录数量和所属账号不变。
7. 家长摘要只读，现有孩子学习流程/邮箱登录/管理员独立权限回归；验证码模板保留用途说明，不出现普通登录码可重设家长密码的混淆。

冻结交验需提供源码清单、API契约、测试入口、模拟器证据及迁移验证。Astra独立复验后才标通过。
