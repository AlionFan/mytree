## 本批验收

- W1 原题完整复现：记录失败分支和修后结果；原图/题干与关键条件一致，原有不支持反例继续准确拒绝。

- W3 练习质量：每个新增题族至少多组固定种子、边界参数和错误答案核验；人工独立核算代表题，检查题干、答案、步骤、来源关系与完整组三题，不仅测试程序自己生成自己接受。
