- 厂商指标不等同于本项目中文手写数学识题准确率；不能在没有同条件证据时宣称某模型“国产所有场景第一”。按真实可用性及题目识别保真度择优，不能为了便宜默认轻量型号。

## 图像链路初查

ai.prepare_image 默认1600边仅说明兼容单题路径；当前默认多题 page_reading 显式使用2400边，且使用 vision_views，应继续检查局部视图及前端压缩后再判断细节损失。不能将1600默认值直接作为当前多题失败根因。

## 验收标准

1. 配置/示例/运行能力状态、PRD及当前规则同步准确型号；历史决定保留历史语境。
2. 同图比对题干数字、符号、上下标、分式、学生原始错误、教师批注角色、几何条件及长图多题归属；不得用数学等价掩盖转录变形。
3. 旧模型和候选同条件小样本评测，区分请求成功、结构可用、内容保真、耗时；小样本不得泛化为总体准确率。
4. JSON/参数适配、超时/鉴权/不可用明确错误、原图保留可重试；禁止静默模型降级、自动重复计费。
5. 冻结后由 Astra 独立核代码与真实调用证据；发布后核运行模型及健康。未实测/未发布不得报完成。

## 选型决定（协议探测后）

现有 NextLabs 目录不含 Qwen3.8-Max、Qwen4-Max-Preview、Seed2.1，不能以较小 qwen3.8-27b 代替 Max。选已可真实调用的新旗舰 `kimi-k3.1-pro` 为优先替换型号；[月之暗面官方发布](https://www.kimi.ai/blog/kimi-k3-1-pro)确认2026-10-24发布及 API 可用。是否适合本项目由下一轮 PAGE_PROMPT 小集决定，不声称国产全部任务第一。

执行方协议探测（三模型各一次、同原创图）：Kimi8.122s、豆包2.0Pro7.538s、Qwen3-VL-Plus5.080s，全部200/stop/JSON合法，返回模型与请求一致；错式未被纠正、批注分离、无作答题不补答案。Astra读取原始合成转录结果核对；这是协议与简单内容检查，不是中文手写准确率。

下一轮已指定 Kimi、豆包2.0Pro、旧GPT在相同3张原创中文公式/批注多题/长图几何上走实际PAGE_PROMPT及归一化路径，共9次，不调用真实儿童资料。Kimi达标再更新统一vision（包括探索者与带图讲解），纯文字tutor不变；如重大漏题/改错，先上报再重新决定，不自动换模型。当前尚未发布。

Astra已目视检查 smallset/preview.jpg 与 truth.json：分式分母 x−a₁、条件a₁=3、学生故意写x−3及x≠3；角色页有两条红批注且第三题无作答；长图三题中直角三角形AB6/AC8/BC10且学生错误面积48。这些为字体生成的原创合成作答，不能标作真实手写。供后续独立核输出的预期。
