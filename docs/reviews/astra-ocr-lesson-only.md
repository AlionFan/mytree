# OCR接收分层与教学原图：方向决定

2026-11-15，astra-lead；执行codex-android。承接共享381/384/386，FR-001/002/032。已查看真实p1.jpg、p1-recognition.json、p1-summary.json及page_reading/reading_registry实际代码。本文件是允许实施的设计，不是识别质量验收通过。

## 决定一：允许只讲原题，不用模糊作答阻塞题目学习

将题目内容可用性与学生作答可用性分开判断，不能把现有所有attention_reasons直接清空。新增`lesson_ready`或同义受控状态，服务端明确区分`analysis`与`lesson_only`接收模式；既有ready不等于已正确判题。具体契约字段同步schema、前后端和证据。

可进入lesson_only：印刷题干/选项/必要图表完整且有来源，问题片段与题干一致；唯一阻断来自作答缺漏、跨题归属不明、草稿转录不一致、批注/涂改难分。第4/5/6题是本次目标样例。未知草图保持未归属，不为了放行复制给两道题，也不能删除后伪称未作答。结构损坏到无法判断题目条件、题干本身模糊、必需选项缺失、依赖图形却无可用原图时仍阻断，并保留局部重识别入口。

该模式从当前原题生成讲解，不传不可靠steps作为学生事实；原笔迹、片段、疑点保存在原识别来源中，UI仍可查看原图。可正常“开始学习”，无需新增强制逐题确认；如需区分只用简短状态“原题讲解”，不恢复用户刚要求删除的长警示。

服务端所有下游须约束：不把此事件记为学生做错、不增加错因统计/掌握证据/成长分、不自动点亮知识点；允许存原题学习卡，类型是lesson而非已判错wrong。模型即使输出学生答案错误也不能绕过此限制。随后孩子独立完成的新练习/检验仍按既有核验规则累计，与这次无法判定的原作答分开。不能让客户端传mode=analysis升级权限。

接收凭据绑定owner、batch、reading、revision、mode、policy_version；重试去重，同题同版本不能同时重复建学习卡/错题卡。新版接收检查不能破坏旧ready路径；取消、来源替换、页码变化后的接收/教学请求与迟到结果均须拒绝或丢弃。当前accepted()只检查凭据寿命，实施时须复核其来源仍有效，不能仅新增mode而遗漏失效链路。

## 决定二：依赖图像的题目给教学模型原图视野

批准服务端短期、账号绑定的题目图像缓存，供teacher多模态请求使用；不增加公开图片URL、不长期保存原照片、不放普通日志。继续NextLabs或官方供应商，涉及读图的模型固定gpt-6.1-sol。源码/配置/实际请求要一致。

依赖图像包含美术字、几何/立体图、图形选项、统计图表等，不能只按“如图”关键词识别。第1题的选项必须以原美术字图形为准，OCR普通汉字只能作为辅助且不能改变图形；第2题必须看到立体图、方向与完整A-D选项。文本与图冲突时以原图可见信息重新判断，不按常识补条件。

缓存默认15分钟绝对TTL、访问不续期；按源图摘要+owner+batch+revision绑定，题裁片关联reading_id和归一化坐标。内存或私有临时文件均可，必须有单图解码像素/字节限制、每账号及全局总字节上限并实测淘汰；仅条数上限不够。先复用已有有效上传内容，不让浏览器任意提供文件路径/远程URL。图片读取每次检查基础账号和来源，不因猜中ID泄露。退出、取消、换图清理对应有效引用；已发送上游请求无法撤回时丢弃迟到输出。

只发足够覆盖本题条件与选项的裁片；裁片边界不可靠时使用本页必要上下文但明确当前题范围，避免把另一题答案当当前作答。不得静默裁掉选项、题号或跨行条件。客户端保留的原图可用于重新识别恢复；缓存过期/进程重启时返回可恢复错误，不偷偷退回仅文字回答图形题。

摘要学习卡可长期存在，但图像TTL不由卡片持久化延长。之后重开依赖图像的旧卡若缺原图，应提供补图入口，不声称仍能完整看原题。缓存接口返回no-store，禁止日志/测试报告记录真实照片base64；固定测试试卷的脱敏证据另存。

## 本批验收

1. p1题号1..10覆盖、无重复和漏题单列统计；现有7 ready只是接收状态，不能称7题识别正确。第4/5/6进入lesson_only，未知草稿原样保留，无学生错误判定和点亮副作用。
2. 故意缺一项印刷条件/图形选项、题干与片段冲突仍不可lesson_ready；只改变作答不确定性不会再阻断清楚原题。后端构造恶意mode字段不能升级判题。
3. 第1/2题真实teacher请求确实包含正确裁片，人工对照美术字与几何选项核查讲解；不能仅看HTTP200或模型说自己看过图。至少保留请求包含图像的脱敏元数据和响应人工核对结论。
4. 缓存过期/逐出/取消/换页/换图、跨账号读取、重复接收及迟到响应测试通过；检查内存/磁盘字节上限和清理，不继承旧图片功能通过记录。
5. 第5题印刷题中a的非零条件并未明确可见：若模型需要a≠0才推严格大小关系，必须讨论a=0时三者相等，不能自动补条件。这属于题目数学条件与教学质量，不以lesson_ready替代判断。
6. 先冻源码/契约及证据再交Astra独立复验，PRD和decisions记录上述接收模式与图像留存边界。不要求更换数据库或放宽成绩核验规则。
