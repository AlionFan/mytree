# EXPLORER-001：按键唤醒的英文探索与上线

2026-11-14，来自用户明确新增指令；覆盖 FR-015 旧版“不含随时打断”，本轮同时授权 FR-017 部署。PRD 由持有者 codex-prd 同步，本文件记录实现范围，不能将自测写成独立验收。

- **拍照模式**：保留拍照/图片/PDF→识别确认→错题整理，无实时播报。
- **探索者模式**：显式点击或空格唤醒摄像头；连续取帧交给当前指定的 `gpt-6.1-sol`，用简短英语描述当前画面并朗读。不是视频流模型接口，首次和每轮延迟取决于模型；每次只处理一帧，画面无变化时不重复积压播报。
- **打断/继续**：按钮或空格立即停止当前声音与后续自动发送；保留本段播放位置，按继续从该位置播放。迟到模型/音频结果不能重新发声。
- **语音交互**：点击说话开始，再点结束；或按住 V、松开提问。先打断播报，开启麦克风；结束后由 NextLabs 的语音模型转录，再结合当前画面英文回复、朗读。只在按键发起时录音，不做常开麦或唤醒词。可取消录音。
- **资源释放**：睡眠、离开页面、切回拍照模式和页面进入后台，停止摄像/麦克风轨道及定时器；醒来再次由按键发起。
- **记录边界**：探索不会新建错题卡、不写练习或成长记录；原始画面/音频/对话不写普通日志。模型供应仍 NextLabs 或厂商官网。浏览器内只保留当前会话。
- **上线**：复用 Joybeat 现有服务器和 DNS，用独立服务/持久化目录，不改变官网路由。可信 HTTPS 验证后启用摄像/麦克风。先以口令保护的个人体验版发布，口令与 API key 仅私有配置；不宣称正式账号/家长授权/多租户隔离完成。

验收：假摄像/假麦克风+假上游检查状态机（唤醒、英文、打断、继续、录音、取消、语音回合、迟到响应、切换模式、后台释放）；合成英文音频实测 NextLabs ASR/TTS；发布后查可信 HTTPS、未授权拒绝、已授权页面/静态资源/模型与隔离记录持久化。物理手机摄像头和扬声器效果须如实标待用户实机体验。

实际供应验证更新：`gpt-4o-mini-transcribe` 通过 NextLabs 将合成英文录音正确转录（2.46s）；`tts-1` 两次、`tts-1-hd` 一次返回上游429。英语朗读优先选设备已有的本地英语声音，不将文字送往浏览器默认云端服务；设备没有本地英语声音时才走已配置 NextLabs TTS，失败明确提示。按句播放并记录词边界，继续从打断处附近接着读；设备不提供词边界时从当前句开头继续。不得将 NextLabs TTS 写成已成功实测。

CSP 保持 script-src self，不开放 unsafe-eval；style-src 的 unsafe-inline 用于已有 KaTeX、MathLive 与可拖动位置的内联排版。上线口令仅保护单家庭体验，不补写正式多用户认证能力。
