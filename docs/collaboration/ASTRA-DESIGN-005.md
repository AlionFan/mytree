# ASTRA-DESIGN-005：探索自然语音与有道配置

负责人astra-lead；执行codex-voice-bank；2026-11-15。状态：设计已下发，待实现/独立验收。对应FR-015、FR-017探索模式、FR-029、FR-018及DEV-003；依据[PRD](../PRD.md)与[协作协议](README.md)。用户要求正常ASR、不要机械合成听感，并授权浏览器配置有道，当前实名认证待审。

## 决定与范围

批准本轮将“不要机械合成声音”落实为**默认模型自然语音，取消浏览器设备朗读优先级**。保留ASR识别与现有探索“看画面→英语描述→按住提问→英语回答”；不将用户要求扩大为真人录音、声音克隆或新Realtime架构。不用模型名替代听感验收，仍标明AI语音，不称真人声音。

本机实际代码：speech.py已接转录/合成，ASR默认gpt-4o-mini-transcribe；explorer.js先尝试speechSynthesis，再请求远程TTS；ai.py合成默认tts-1/alloy。PRD仍写未配置/不支持打断，执行方需按实际状态更新并保留历史验证边界，不能继续把已存在代码或配置默认值等同真实服务正常。

允许执行方认领speech/ai配置、explorer及必要UI、语音测试/证据、README/PRD/decisions/部署配置；有道沿DESIGN-004现有配置流程处理，不修改题库候选信任、答案隔离或学习规则。Astra只维护独立设计与后续评审。

## A. ASR与自然TTS（P0）

1. 保留gpt-4o-mini-transcribe作为当前ASR，客户端只提交本次用户明确录下的声音，不用TTS/浏览器SpeechRecognition冒充实际转录。录音中、识别中、失败/取消清楚；空音频、噪声/无法识别不提交伪造提问。识别文本可见且能改正后重问，不能因用户口音改写数学事实或题文。
2. 默认模型TTS，首选执行方提案gpt-4o-mini-tts，但**具体provider/model/voice/instructions组合必须真实可调用**。NextLabs或厂商官网限制不变；禁止客户端注入任意模型、音色、endpoint或风格指令。配置、示例、能力展示、运行与发布证据一致；失败保留文字与重试，不静默转speechSynthesis、tts-1或另一供应商。
3. 固定简短英语指导：自然、温和、清楚、对孩子讲话，正常停顿、不过度逐词断句、不夸张表演。使用当前供应商支持的标准音色，不模拟具体真人。instruction控制方式仅向支持的模型发送；不把指导句混进朗读正文或实际念出来。用户原话可中文/英文，探索回答仍沿既有英语行为；不顺带扩大多语言朗读范围。
4. 生成文字立即可读；TTS慢/失败不清空文字，不重新请求视觉/问答以“重试朗读”。一个有效文字结果至多对应一次主动TTS请求；重复点击/迟到响应不重叠播放。若请求取消后是否计费未知，不宣称exactly-once计费。
5. 保留手动打断、按住提问打断和已有已解码音频的offset续播。暂停→继续复用内存音频，不重新合成；提问回答后可恢复原播报，不从头重念、不把旧回答播到新题。退出探索/账号切换/睡眠停止录音与播放，释放媒体流/音频引用；迟到TTS/ASR不得自动播放或提交。
6. 请求与返回保持既有/api/speech契约，错误可追溯且不泄露key；大小、时长、并发和超时仍受限。检查真实编码与可解码性，不仅接受audio/*或200。网页端遇自动播放限制时给明确点击恢复，不产生无限请求。声音与录音不进普通日志或共享文档。

### 模型有效期

2026-11-15核对[官方语音指南](https://developers.openai.com/api/docs/guides/text-to-speech)与[退役表](https://developers.openai.com/api/docs/deprecations)：gpt-4o-mini-tts系列/tts-1计划2027-01-06关闭，gpt-4o-mini-transcribe计划2027-02-26关闭。这是官网计划，不是对NextLabs供应能力的保证。允许用目前供应商实测可用组合完成本次修复，同时在README/决策明确此过渡限制。不能宣称长期可用；后续替换需核实供应商及接口差异再决定，不本批自动切Realtime。若当前候选不可用，报具体错误及可用替代提案给Astra，不以机械声音掩盖失败。

## B. 浏览器配置有道（与语音独立推进）

- 用户已授权在浏览器配置，执行方继续其受控浏览器会话，避免另一个代理抢占同页。用户登录/验证码/身份认证待审阶段如实等待；不代绕审核、不重复索要已交付密钥，不因有道阻塞语音实现。
- 登录成功后检查当前账户、实名认证状态、精品题库服务是否可开通、应用是否存在。可在已授权配置范围内填写/创建适用API应用，不新增付费套餐/充值/其他服务，除非用户明确授权。
- 仅查看配置所需信息，不把身份证、手机号、密钥或验证码写到普通截图/日志/共享消息。凭据只走既有安全本地配置路径，不粘贴进聊天、代码或PRD；无法安全转存时停在具体步骤由用户完成，不重复要求整套注册。
- 状态分开记录：未登录、实名审核中、服务未开通、应用已创建、私有配置已保存、真实查询已成功。实名未通过/服务不可用时，网站维持未配置或明确不可用，不能伪造题库已接通。
- 真正凭据可用后，按DESIGN-004用一条自编、短于50字符的非个人题干测试text协议及候选，再核对部署状态。验证不上传孩子照片/声音，不查询历史个人题库。候选始终未核对，不改原题/答案规则。若仍待审，交付已完成步骤及唯一剩余条件，不反复轮询审核状态或创建无授权自动化。

## 供应商实测后的模型决定（消息241）

执行方报告NextLabs当前不提供可用gpt-4o-mini-tts，一条自编英语调用失败；拟用其支持的tts-1-hd/nova。Astra批准以 **tts-1-hd/nova作为本次显式选定组合进行实现与试听**，ASR继续gpt-4o-mini-transcribe；它不是运行时遇错静默降级。最终自然听感与真实播放仍按V2验收，不凭HD名称宣布“不机械”。tts-1-hd不支持前述instructions控制时不得发送该字段或将风格指令塞入input；通过实际音色与正常语速验证。配置、示例、能力状态、发布记录同步此选型，gpt-4o-mini-tts保留为实测失败事实，不宣称运行采用。官网2027-01-06计划关闭限制同样适用，NextLabs实际生命周期仍需另核实。本决定不改变既定供应商，不要求用户另开新供应商账号。
