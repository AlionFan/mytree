# 小树同学 · 主流程验收约定（2026-11-14）

> 产品需求、优先级、业务边界与验收编号以 [PRD](PRD.md) 为准；本文细化页面体验。Codex / Claude 共用 [协作协议](collaboration/README.md)。下文按时间追加的约定中，后项覆盖前项；已删除的手动录题入口不能因旧段落恢复。

依据本地《项目思路与准备清单.md》和《技术方案与选型.md》，先完成网页学生端→错题诊断→分级提示与数形结合→针对练习→复习排期→知识树与家长看板的闭环。初版保留手动流程；本次已授权接入 NextLabs。选择照片只在本机预览，用户点击识别后才发送到已配置的模型。

首屏直接显示今日安排与学习入口。温暖的纸白、深绿、少量橙色，像孩子自己的数学学习手册；用清楚的步骤编号和图形代替宣传文字。保持现有无前端构建依赖的实现。桌面 1440x900 双栏工作台，手机 390x844 单栏；图形与公式不能裁切，按钮至少 44px，可用键盘访问并有焦点样式，尊重减少动画设置。

## 核心动作

1. 选示例或手动输入题目和作答，逐行校验。照片先本机预览，点击识别后压缩并调用视觉模型，识别结果在题目/步骤输入框中可修改，明确确认后才调用诊断并写入记录；未配置读图 API 时提供手动录入。
2. 定位第一个错误；提示按 1→2→3 解锁；图形需要主动展开，图形中的公式可用于解释但不在低级提示前自动泄露完整答案。面积图明确正长度的适用条件。
3. 生成 3 道变式题；不把原题重抄或未分解的等价式判成做完。批改持久化到当前浏览器的演示学习档案，重复提交正确答案不重复计分。
4. 设置每周空闲日和时间，按 1/3/7 天阶段排复习。练习成功会更新任务与知识树，错误记录作为历史保留。单次正确标为初次点亮，不宣称完全掌握。
5. 家长看板展示同一演示档案的错因、练习、知识点、复习及最近记录。当前无账户绑定，不可宣称为正式家长授权系统；服务默认仅本机运行。

## 内容状态

- 加载：检查、生成练习、读图、AI 追问和读取画像时禁用对应动作，显示处理状态。
- 空：新档案没有错题/复习/点亮，提供开始检查入口。
- 错误：表达式不支持、网络断开、输入格式异常时显示具体恢复动作。
- 部分：后续步骤未检查；不支持的图形保留诊断并说明；模糊识别标出疑似行，多题/不支持题型不自动进入诊断。AI 等式或提示校验不通过时显示已校验提示，并明确标注回退。
- 成功：诊断、练习、空闲时间保存均显示确认及下一步。
- 权限：点击识别前照片仅本机预览，界面说明点击后发送到模型服务；原始图片不落盘。密钥仅在服务端私有文件/环境变量；无麦克风权限请求。家长页明确演示状态。

模型由服务端配置 NextLabs 或模型厂商官网，密钥只放服务端环境变量；拿到 API 前不宣称接通模型或真实语音。域名解析已有记录，部署与 HTTPS 需单独验证，不能把本机结果描述为线上交付。
